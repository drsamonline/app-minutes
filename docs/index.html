Minutes

Decisions and actions, separated as you type — so the follow-up list exists before the meeting ends.

Open Minutes
Status Built and working offline: a shorthand that puts each line in exactly one list (d: decision, a: action, topic:, n: note); owners only when you type one; a follow-up list with the unowned actions marked; a meeting autopsy that measures each topic and names the ones that produced nothing; and a Markdown export whose action count equals the count on screen.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: audio recording and transcription — both specs forbid it, and the app says so rather than shipping a microphone it would only misuse. The clock comes from the moments you press “Mark a new topic now”.

What it does

  • Separates decisions from actions as you type, so nothing can land in both lists.
  • Records an owner only when you type one (@Name), and marks the rest UNOWNED — never handed to the last speaker.
  • Flags a decision with no mover, because a resolution nobody moved is not a resolution.
  • Measures the meeting: minutes per topic, and which topics produced no decision and no action.
  • Exports Markdown with every action and its owner, and states the count so it can be checked against the screen.

What it will not do

  • Record audio or transcribe. It structures what you type — which is why it works with the microphone off and no signal.
  • Guess an owner. An unowned action stays unowned and is listed as such.
  • Guess the attendees. With no names typed, the minutes say “Attendees not identified” rather than promoting the names in your lines.
  • Invent minutes from silence. No decisions and no actions means exactly that, with no summary written over it.
  • Use a key or a network. No fetch, no endpoint; CSP connect-src 'none'.

When things go wrong

CaseWhat happens
Bad inputNo attendee names → “Attendees not identified”, names kept unnamed. A decision with no mover is flagged. A line with no marker becomes a note, not a decision.
No networkNothing changes; there is nothing remote on the path.
Storage full or unavailableThe app says NOT SAVED at once and tells you the minutes cover only what is on screen — export them now.
Corrupt saved stateReported and offered for export; never replaced with a blank meeting, which would look like a meeting where nothing was decided.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js — the spec's countable “done means” is asserted there.
